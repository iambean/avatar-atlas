在任意终端中使用。需要 Git 和 Node.js 20 或更新版本，安装后的应用从项目本地加载头像。

01 · 安装工具 · GitHub · v1.3.0
npm install --global github:iambean/avatar-atlas#v1.3.0
02

进入项目，执行初始化

avatar-atlas init

自动安装头像、索引和署名文件，并生成可直接导入的 JS / TS 接口。重复运行会跳过未变化的文件。

03

直接在代码中使用

avatarUrl('portrait-cartoon-01')
findAvatars({ category: 'cartoon' })

用头像 ID 获取本地图片地址，也可按分类、年龄和性别筛选。支持手写代码、任意编辑器或 AI agent。

04

按需添加，随时更新

avatar-atlas add landscapes
avatar-atlas update
avatar-atlas status

只下载变化的素材，更新时保留已有头像引用；检查本地文件是否缺失或被修改。

按分类安装、自定义目录和接口示例
avatar-atlas init --categories cartoon,geometry
avatar-atlas init --dir public/images/avatars --base-url /images/avatars
avatar-atlas init --cwd ./my-project --json

有 src/ 的项目会生成 src/lib/avatar-atlas.ts 或 .js；其他项目生成根目录 avatar-atlas.mjs。导入路径按调用位置调整。

import { avatarUrl, avatars, findAvatars } from './lib/avatar-atlas';

const currentAvatar = avatarUrl(user.avatarId);
const options = findAvatars({ category: 'cartoon', gender: 'female' });

配置和 lock 文件可提交到版本控制。图片使用 CC BY 4.0，工具会自动保留授权与署名；CLI 和接口代码使用 MIT。
